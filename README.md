# Anurag University: Campus Outbreak (FP & Meta Quest 3 VR)

First-Person & Meta Quest 3 WebXR 3D Zombie Survival game set across the Anurag University Venkatapur Campus, featuring Blender 5.3 sculpted assets, a deployable transparent hi-tech hex-grid shield, multi-weapon right-hand arsenal, pickable campus rods/branches, and 6 faculty zombie levels culminating in the CEO Boss.

## Play Online
Open `index.html` over HTTPS (Render / Vercel) in any PC browser or directly in **Meta Quest 3 Browser** and click **Enter Meta Quest**.

## Local Server (PC + Meta Quest 3)
```bash
python Start-Server.py
```
- PC: `http://localhost:8765/`
- Meta Quest 3 (Wi-Fi): `https://<YOUR-LAN-IP>:8443/`
